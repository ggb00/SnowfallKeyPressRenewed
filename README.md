# SnowfallKeyPress Renewed

**Renewed** version of SnowfallKeyPress addon for **World of Warcraft: Wrath of the Lich King (3.3.5a)**\
It has improved optimization and correctly works for all keyboard layouts.

<sup>Made with the help of AI.</sup>

# Installation

1. Download the addon by clicking the link below:
   - [Download SnowfallKeyPress Renewed](https://github.com/ggb00/SnowfallKeyPressRenewed/archive/refs/heads/main.zip)
2. Unzip the downloaded archive.
3. Rename the folder inside the zip from `SnowfallKeyPressRenewed-main` to `SnowfallKeyPressRenewed` (folder name should be the same as `.toc` file).
4. Move the `SnowfallKeyPressRenewed` folder to your World of Warcraft AddOns folder.
    - Example: `C:\World of Warcraft WotLK\Interface\AddOns`
5. If you have WoW open - restart the game for the addon to load in properly.
6. If you previously had old `SnowfallKeyPress` addon installed, you need to remove it or disable in-game to prevent conflicts.
